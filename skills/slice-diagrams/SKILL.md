# slice-diagrams —— 制图

## 何时使用 / 不负责

- 用于：设计、计划或分析文档需要配图时，用 Mermaid 画结构、依赖、流程或时序图。
- 不负责：ASCII 画框；ASCII 只留给 UI mockup 与清单。

## 入口步骤

1. 读取正文末尾 `## 当前模块配置` 中本模块规范的绝对路径（注入块「规范文件」行），先 read 规范再动手。
2. 该路径标为「（缺失）」或读取失败时：报告该确切路径并询问用户，不自行补规则、不换别的文件。
3. 按规范选图、画图；交付前按规范做结构校验，并如实声明验证程度。
4. 派发子代理时，按注入块中「派发角色」行的 provider/model 路由；加载本 Skill 本身不切换当前会话模型。

## 与其他模块

- `slice-planning`：主计划、方案与设计文档的配图。
- `slice-patch-delivery`：薄文档需要结构图时；文档本身仍只引用 patch，不复制 diff。
- 只按注入的绝对路径读取；读不到就报告该路径，禁止 `find /` 或扫描盘符。
